Technological developments in data collection and processing methods are transforming sports analytics at the same pace.
Basketball is an important branch that stands out in terms of the applicability of all new techniques in this transformation.
Although there are many studies on player performance indicators in the existing literature, there are still gaps in the models that systematically determine which variables are really effective and subject players to a completely objective ranking.
In this study, a hybrid framework combining Decision Trees (DT) and Analytic Hierarchy Process (AHP) is proposed to address this gap.
The model, which is tested using data from the 2024-2025 NBA season, first decomposes the performance criteria that directly affect the match result with the DT algorithm and calculates the importance levels of these criteria through Gini indices.
These objective weights are then incorporated into the AHP system to generate player performance scores.
The most important difference of this method is that it provides a completely data-driven weighting instead of the subjective expert opinion seen in classical AHP applications.
The results of the analyses show that the proposed model is effective in identifying success factors and produces more consistent player rankings than individual methods.
The study aims to provide coaches and team managers with concrete, applicable results for strategic planning In AHP coding, the classified variables specified for each team were manually modified because they differed.
The data was selected according to the specified variables, and each player's performance was based on the specified factors.
In this regard, the effective variables were determined in the Python program called DecisionTree(code), while in the AHP code, the weights of these variables were calculated, and the players' performance was determined, and the ranking was carried out.
